# Unity combat reference

These files are research outputs from the original assets in `G:/test/FPSGame`.
The original project is read-only. `prepare_combat_truth.py` copies the required
assets and their avatar metadata into an isolated Unity project under `temp`.

The available working batch importer used Unity 2022.3.62f3 with `-noUpm`.
The reference project was authored with Unity 2019; these outputs use its actual
clips and avatar metadata, but importer-version differences still require visual
comparison when changing character appearance.

- `unity_animation_events.json`: Unity API clip lengths and event times in seconds;
  generated by `AnimationUtility.GetAnimationEvents`, including string parameters.
- `*.kdance.bin`: 30 fps full transform poses sampled by a manual PlayableGraph,
  with root motion disabled. The first frame is evaluated before recording.
- Boss Idle/Run/Hit/Dead/Skill1/Skill2 are baked on the original Lancer avatar.
- Reload/shoot are baked on the militia and alien avatars, preserving retargeting.

From the repository root:

```powershell
python tools/prepare_combat_truth.py
& 'C:/Program Files/Unity/Hub/Editor/2022.3.62f3/Editor/Unity.exe' -batchmode -nographics -noUpm -quit -projectPath G:/FPSGame/temp/unity_combat_truth -executeMethod BakeCombatTruth.Run -logFile G:/FPSGame/temp/combat-truth.log
python tools/export_combat_events.py
```

`BinToTres` converts the retained pose binaries into the shipped AnimationLibrary
resources via the monster-view tool's `--bin2tres:level2_boss`, `--bin2tres:toon`
and `--bin2tres:toon_alien` options. The runtime installs event method tracks on
immutable library copies, so exported animations remain independent of this
research directory. `Combat/AnimationEvents` and `Combat/ActualShots` verify the
result in the source project and the actual exported executable.
